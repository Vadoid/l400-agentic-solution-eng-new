# Spec Ledger Skill (`spec-ledger`)

## Overview
This skill implements Intent-Driven Engineering spec governance, audit-trail preservation, and progressive disclosure across `docs/design/DESIGN-*.md`:
1. **Immutable Prompt & Design Deltas Separation**: Splits each `docs/design/DESIGN-*.md` into the human's original specification body (`spec_sha256`) and the bottom `## Implementation Notes & Design Deltas (Auto-Generated by Agent Harness)` section, preserving the human's original prompt as an untouched audit trail while recording "what really happened" (human clarifications, architectural deviations/workarounds, and assumptions).
2. **Auto-Scaffolding & Delta Verification**: When a specification's target files are implemented (`status: implemented` or `in_progress`) and `## Implementation Notes & Design Deltas (Auto-Generated by Agent Harness)` is missing, `run.py` automatically scaffolds the section at the bottom of the file and reports any specs with placeholder/missing notes in `missing_design_deltas`.
3. **Lean, Zero-Duplication YAML Frontmatter & Prompt Drift Detection**: Writes only `spec_id`, `status`, `spec_sha256`, `depends_on`, and `target_files` into each `DESIGN-*.md` frontmatter (avoiding duplication with the Markdown body) and computes `spec_sha256` on the human's original specification body to detect when a specification prompt has been modified.
4. **Compact Progressive Disclosure Routing Index**: Generates a fast, deterministic `docs/design/index.md` (`ledger_version: "1.0"`) containing a routing table and one-line summaries per specification.

## Example Usage

```python
import sys
import os
import json

# 1. Append the skill path dynamically
sys.path.append(os.path.abspath('.agents/skills/spec-ledger/scripts'))
import run

# 2. Read the environment config (stored at the root of the project)
with open('agent-config.json', 'r') as f:
    config = json.load(f)

# 3. Call the function to synchronize YAML frontmatter and regenerate docs/design/index.md
result = run.index_design_specs(
    design_dir="docs/design",
    workspace_root=".",
    force=False,
    check_only=False
)
print(json.dumps(result, indent=2))
```
